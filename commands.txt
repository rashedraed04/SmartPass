======================================================
     SMART STUDENT HELPER - MASTER COMMAND LIST
======================================================

------------------------------------------------------
1. BACKEND (Django / Python)
------------------------------------------------------
Open a terminal inside the 'smart_student_backend' folder:

Wake up the Virtual Environment:
.\venv\Scripts\activate

Turn on the Server (Wi-Fi Mode for phone testing):
python manage.py runserver 0.0.0.0:8000

------------------------------------------------------
2. FRONTEND (Flutter / Dart)
------------------------------------------------------
Open a NEW terminal inside the 'smart_student_frontend' folder:

List all available virtual phones:
flutter emulators

To run on the virtual phone:<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<<
flutter emulators --launch flutter_emulator
flutter emulators --launch Redmi13C 

Install and run the app:
flutter run

------------------------------------------------------
3. SERVER MANAGEMENT & TROUBLESHOOTING
------------------------------------------------------
Run these inside the backend terminal:

Activate Virtual Environment:
.\venv\Scripts\activate

Run the server:
python manage.py migrate
python manage.py makemigrations

Run the Server (Wi-Fi/Physical Phone Mode):
python manage.py runserver 0.0.0.0:8000

Change a User's Password:
Useful if you forget your test credentials.
python manage.py changepassword <username>

Turn off / Stop the server safely:
Press: Ctrl + C

Quick Restart:
1. Press: Ctrl + C
2. Press: Up Arrow key
3. Press: Enter

Emergency Server Kill (If Ctrl+C freezes):
Open a completely new terminal and run:
taskkill /F /IM python.exe

Force Password Reset (If you get locked out):
python manage.py changepassword admin@test.com
